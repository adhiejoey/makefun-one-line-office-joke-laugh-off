# One-Line Office Joke Laugh-Off

Entry for the make.fun bounty **One-Line Office Joke Laugh-Off** (`u-suzy-one-line-office-joke-laugh-off-f574ac73`).

Running `node main.ts` writes a single original one-line office joke to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The entry:

> I asked for a raise and HR threw me a pizza party, so now I'm technically paid in pepperoni and regret.
